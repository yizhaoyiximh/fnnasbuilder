Built-in configuration additions for FnNAS image construction:
  CONFIG_BTRFS_FS=y
  CONFIG_FAT_FS=y
  CONFIG_MSDOS_FS=y
  CONFIG_VFAT_FS=y
  CONFIG_BLK_DEV_LOOP=y
  CONFIG_PARTITION_ADVANCED=y
  CONFIG_MSDOS_PARTITION=y
  CONFIG_EFI_PARTITION=y

CONFIG_MSDOS_PARTITION=y enables the DOS/MBR partition parser. It is required for
losetup -P to create /dev/loopNp1, /dev/loopNp2, etc. from FnNAS MBR disk images.

The bundled fnnas-vmlinux-arm64.kernel is passed to `container create --kernel`.
